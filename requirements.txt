# Python 3.11 — this is the ONLY version the published results were verified on.
#
# Versions are pinned exactly because the map is sensitive to the linear-algebra
# stack: the sparse Gram product X @ X.T varies by ~5e-9 relative between BLAS
# builds, which is enough to change the anchor assignment. See CORRECTIONS.md #2.
#
# Verified on Python 3.11.15, macOS arm64, 2026-08-06: all 15 validation gates
# pass and code/verify_reference.py reproduces all 28 published metrics.
#
# Do not run this on Python 3.9. It completes and still passes all 15 gates, but
# the anchor tie-break resolves differently and E1 drifts (Spearman 0.676
# instead of 0.687).
#
# Python 3.10: these pins do not resolve at all (numpy 2.4.6 needs >=3.11; 3.10
# tops out at numpy 2.2.6). The unpinned 3.10 stack still passes the test suite
# and reproduces all 28 published metrics — see the "Python 3.10" section of
# README.md — but it cannot rebuild the published map from a corpus.
